Copy Deans style from `git log -15`: lowercase imperative subject, no period, short (~50 chars). Optional ONE short why-line. Never bullet lists, never `file: what` lines, no verbose AI-style descriptions. "simple ass commit messages".

**Why:** corrected many times; "we have already talked about this multiple times" (2026-11-25).
**How to apply:** project-specific details in project memories. Related: [[git-workflow]], [[no-ai-attribution]].
