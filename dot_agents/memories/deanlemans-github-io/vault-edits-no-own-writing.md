When consolidating or restructuring notes in the vault (`content/`), dont write anything myself. Only use text that already exists in the vault: move it, merge duplicates, delete exact repeats, add links. No new explanations, legends, tables, summaries, "see X for Y" sentences, annotations on links, renamed headings, or typo/wording fixes.

**Allowed exceptions, only inside a task that needs them:**
- Linking glue in Deans tone when linking zettels in sentences ([[linking]]): a clause at most, listed in the report.
- Claim titles + pretty titles/aliases ([[evergreen-notes]], [[linking]]): take the words from the notes own text or filename wherever possible ("the real claim is already in the note").
- Frontmatter fields the conventions require (type, tags, publish...).
- When Dean explicitly asks me to write or reword (e.g. "integrate it into vault rules, change the wording a bit so it fits"), then [[writing-voice]] applies.

**Why:** "the rule is, dont write yourself, only use whats already in the vault" after I added my own legends, definitions and connecting sentences during a consolidation pass (2026-11-18); "you write ZERO FUCKING CONTENT" (2026-11-16).
**How to apply:** default links are bare under an existing `## Related` list; in-sentence title links only for zettel linking tasks. If something is missing (undefined emoji legend, broken link target), report it to Dean instead of filling it in.
